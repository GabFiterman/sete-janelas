# ChallengeLett: Domínio dos Fundamentos da Web

Desenvolvido originalmente como um desafio de estágio em 2022, este projeto atua como a prova fundamental de que compreendo o que acontece sob o capô dos frameworks.

### Pontos de Destaque Técnico

- **Arquitetura Pura (Vanilla JS)**: Implementação manual de paginação, busca e tratamento assíncrono consumindo a API pública do GitHub sem o uso de dependências externas.
- **UI/UX e Figma**: Planejamento completo do design da interface focado em usabilidade e responsividade refinada antes da escrita de código.
- **CSS Estruturado**: Escrita de estilos performáticos organizados através da metodologia B.E.M., mantendo o código limpo e sustentável.
